# Seismic Frequency Filter

Интерактивный инструмент для частотной фильтрации реальных сейсмических данных
с контролем параметров фильтра и сравнением результата до/после обработки.

## Цель проекта

Разработка desktop-приложения на PySide6, позволяющего специалисту-геофизику:
- загружать сейсмические данные в формате SEG-Y;
- интерактивно подбирать тип и параметры частотного фильтра;
- видеть амплитудно-частотную характеристику фильтра и спектр данных;
- сравнивать исходные и обработанные данные;
- сохранять результат в SEG-Y.

## Стек

- **Python** 3.13
- **PySide6** — GUI
- **PyQtGraph** — интерактивная визуализация
- **NumPy**, **SciPy** — вычислительное ядро и фильтрация
- **Segyio** — чтение/запись SEG-Y
