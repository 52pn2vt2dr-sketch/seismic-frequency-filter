# my-geo-project

Учебный проект по геофизике: вычислительная библиотека и GUI-приложение.

## Цель проекта

Разработка переиспользуемой вычислительной библиотеки для обработки геофизических данных
и итогового GUI-приложения на PySide6.

## Установка

poetry install

## Структура

- src/ — вычислительный код
- notebooks/ — эксперименты и исследование данных
- tests/ — тесты
- app/ — GUI

## Окружения

- Conda `geo-ds` — Data Science (JupyterLab, NumPy, SciPy, Pandas, Segyio)
- Poetry `.venv` — разработка библиотеки и GUI
